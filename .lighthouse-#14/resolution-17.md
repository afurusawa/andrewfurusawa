## Resolution

**Density:** Lean must-have shell + short optional pack (approved for v1, not required to ship).

### Must-have shell (v1 required)
- Dark Neon Cyber Basement **palette** + neon accents
- **Terminal/pixel-leaning body** type + **radical header** treatment
- **Frames-feel sidebar** with beveled nav: **About · Skills · Contact**
- **Content cards / intro boxes** for the core trio
- **Cosmetic hit counter** (static / non-interactive theater)
- **Simple chrome dividers** between sections
- **Period footer** line ("best viewed in…" / © theater)
- **Readable focus** styles on interactive controls

### Optional pack (v1-approved, not required)
- Under-construction / caution / coming-soon graphics
- Small badge strip (2–4 badges)
- **One** background texture: starfield **or** circuit (not multi-texture stacks)

### Hard no / deferred for v1 chrome
- Web-ring / community badge row
- Multi-texture / stacked backgrounds
- Large badge walls
- Blink/marquee on body copy or nav labels
- Autoplay anything
- Soft glow / divider motion is not a chrome must; only if later accessibility policy allows

Shared understanding confirmed with author after grilling.
