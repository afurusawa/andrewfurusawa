## Question

Which **Neon Cyber Basement** chrome elements from the dark mood board are **must-have for v1** of the `/90s` experiment, which are optional nice-to-haves, and which are explicitly deferred?

Inventory to sort (not exhaustive — use the mood board as the full catalog):

- Color palette / neon accents
- Background textures (starfield, circuit, grid, marble, etc.)
- Typography (pixel/terminal body vs radical headers)
- Beveled nav buttons and GIF-style web buttons
- Hit counter (static/cosmetic)
- Under-construction / caution / coming-soon graphics
- Chrome/GIF dividers and blinky link styling
- Sidebar nav chrome and content cards / intro boxes
- Table layouts for list-y content
- Web-ring / community badge row (cosmetic)
- Miscellaneous 90s badges ("I ♥ HTML", Netscape Now, etc.)
- Footer / "best viewed in…" credit line

Also decide any hard **no**s beyond map out-of-scope (e.g. specific blink patterns).

Standing preference: faithful kitsch with a short leash on motion/noise; dark only for v1; cosmetic theater only.
