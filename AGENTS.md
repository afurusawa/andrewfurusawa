## Navigating Project Context

- **Always-on rules:** this file.
- **Orientation:** read `docs/MAP.md` next when work spans more than one file or module, or when you do not know where to start.
- **Path inventory:** open `docs/agent-context-map.md` when you need to know where a file lives. Read the one section you need.
- **Active work:** `PLAN.md` holds the objective, the active slice, the remaining backlog, and a thin ledger of finished work. Do not load archived plan narratives unless you must.
- **Domain meaning:** open `CONTEXT.md` only when terminology or product language is at stake. Search its headings instead of loading the whole glossary.
- After orientation, open the smallest set of files the task needs. Search for what you need instead of dumping whole files.
